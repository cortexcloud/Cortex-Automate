# Sub Agent: ตรวจหลักฐาน (ภาพ + คลิป) ก่อนแนบ Linear

**สถานะ: ทดลองใช้ตั้งแต่ 24 ต.ค. 2026** — เก็บไว้ต่อเมื่อจับภาพ / คลิปที่ผู้ใช้จะทักได้ก่อนแนบ และลด token ของ session หลัก · ไม่มีไฟล์อื่นอ้างถึงไฟล์นี้ ลบได้ทุกเมื่อ
**กับดักใหม่ที่พบให้รายงานกลับ session หลักเพื่อลง `cortex-card-test/references/traps-full.md` — ห้ามเก็บไว้ในไฟล์นี้**

## 4 ปัญหาที่ต้องจับให้ได้ (ผู้ใช้เคยทัก)

| # | ปัญหา | นิยาม "ไม่ผ่าน" |
|---|---|---|
| P1 | **วงไม่ตรง Expected** | กรอบแดงไม่ได้ล้อมสิ่งที่ข้อความ Expected พูดถึง (ล้อมแถวอื่น · ทั้งคอลัมน์ · ผิดแผง · กรอบชนขอบจอ · กรอบทับตัวอักษรที่ต้องอ่าน) |
| P2 | **คลิปจอขาว** | ในคลิปมีช่วงจอว่าง / ขาว ≥ 3 วินาทีติดกัน หรือรวมกัน > 20% ของความยาว · หรือจอว่างตอนต้น > 2 วินาที |
| P3 | **เร็วเกินไป** | ช่วงที่กรอบแดง / ตารางเทียบอยู่บนจอสั้นกว่า 1.2 วินาที (คนดูอ่านไม่ทัน) · หรือเวลาที่มีกรอบรวม < 1 วินาทีต่อ Expected |
| P4 | **ภาพ Expected ไม่สื่อความหมาย** | เปิดภาพแล้ว**บอกไม่ได้โดยไม่อ่านชื่อไฟล์**ว่ากำลังพิสูจน์ Expected ข้อไหน: ไม่มีกรอบ / ไม่มีป้าย Expected / ค่าที่ต้องเห็นไม่อยู่ในภาพ / ไม่มีตารางเทียบทั้งที่ Expected เป็นค่าตัวเลข-ข้อความ |

## สิ่งที่ session หลักต้องส่งมาใน brief

- path โฟลเดอร์หลักฐาน (เช่น `clips/SBH-xxxx dev-x 2026-10-24/<ชุด>/`) จาก `collect-evidence.mjs` (มี `<คำนำหน้า>-NN.png` + `.webm` + `index.md` ชื่อ step เดิม)
- รายการ TC: เลข TC · ข้อความ Expected ทีละข้อ · ภาพ / คลิปใบไหนเป็นของ TC ใด (หรือให้แมปจากชื่อ step ใน `index.md` — ชื่อ step มีเลข TC)
- ระบบที่รัน (dev-x / SBH Prod) · ข้อยกเว้นที่ผู้ใช้ตกลงแล้ว (เช่น TC 2 ใบใช้คลิปเดียว)

ขาดอย่างใด → ตรวจเท่าที่ทำได้ และระบุว่าข้อไหนตรวจไม่ได้เพราะขาดอะไร

## ขั้นตอน (ทำตามลำดับ ห้ามข้ามขั้น 2)

```bash
export PATH="/c/Program Files/nodejs:$PATH"
# 1) วัดค่าจากพิกเซล — ภาพทั้งโฟลเดอร์ + คลิปทุกไฟล์ (ผลเป็นตาราง + JSON ใน .cache/evidence-check/)
node .claude/skills/cortex-card-test/scripts/image-stats.mjs "<โฟลเดอร์หลักฐาน>" --json .cache/evidence-check/<ชุด>-images.json
node .claude/skills/cortex-card-test/scripts/image-stats.mjs --clip "<คลิป.webm>" --json .cache/evidence-check/<ชุด>-<คลิป>.json   # ทีละคลิป
```

**ขั้น 1 — สคริปต์** ให้ค่าต่อภาพ: ขาว% · ตัวอักษร% · จำนวนกรอบแดง 3px ของเรา (ตัดขอบ 1px / ปุ่มแดงของแอปแล้ว) · ป้าย~ (ประมาณ — ป้ายไทยสั้นๆ อาจตรวจไม่เจอ) · ตารางเทียบ · ธง (เกือบว่าง / ไม่มีกรอบ / กรอบชนขอบจอ / กรอบ >60% จอ) · ต่อคลิป: ความยาว · ขนาด · ช่วงจอว่าง · ช่วงที่มีกรอบแดงและช่วงที่สั้นกว่า 1.2 วินาที
ใช้ธงเป็น**จุดเริ่มสงสัย** ไม่ใช่คำตัดสิน — ธงว่าง ≠ ผ่าน

**ขั้น 2 — เปิดดูภาพทุกใบด้วย Read ทีละใบ ห้ามสุ่ม** แล้วเขียน "หลักฐานในภาพ" ต่อ Expected แต่ละข้อ:
- **ต้องยกข้อความที่เห็นในภาพมาอ้างตรงๆ** (เช่น `"บัญชียา = NED"`, `"ยืนยันการตรวจสอบสำเร็จ"`, แถว `med0000007 … 33.25`) — ยกไม่ได้ = Expected ข้อนั้น**ไม่มีหลักฐาน** (P4)
- บอกว่ากรอบแดงล้อม**อะไร** (แถวไหน · ช่องไหน · ปุ่มไหน) และสิ่งนั้น**คือสิ่งที่ Expected พูดถึงหรือไม่** (P1) — กรอบล้อมแถวอื่น / ทั้งตาราง / ชนขอบจอ = ไม่ผ่าน
- ป้ายบนกรอบตรงความหมายไหม: ค่าที่ต้องเห็น = `Expected` · สิ่งที่กรอก = `กรอก` · ปุ่ม = `กด` · toast = `แจ้งเตือน` · ภาพ "ผ่าน — …" ที่ไม่มีกรอบเลย = ไม่ผ่าน P4 (ยกเว้นเป็นภาพบริบทที่ไม่ได้ใช้แนบ)
- ภาพ "ก่อนกด" ต้องเห็นปุ่มที่กำลังจะกดพร้อมกรอบ `กด` · ภาพ "หลังกด" ต้องเห็นผลของการกด (toast / สถานะใหม่ / หน้าใหม่) ไม่ใช่หน้าว่างกำลังโหลด
- Expected ที่เป็นค่า (ตัวเลข / ข้อความในช่อง) ควรมี**ตารางเทียบค่า** (หน้าจอ vs Expected · ผล ✓) — ถ้าไม่มี ให้ระบุว่าค่านั้นอ่านจากภาพได้ตรงไหน
- เกณฑ์คุณภาพกรอบ (R59): เส้นกรอบไม่ผ่ากลางตัวอักษร · ป้ายไม่ทับข้อความ / ช่องกรอก · ตารางเทียบไม่บังคอลัมน์ที่ต้องอ่าน · เมนูข้างไม่กางค้างบัง · ไม่มี dialog / popover ค้างที่ไม่เกี่ยว
- ชื่อไฟล์ ≤ ~95 ตัวอักษรและมี `.png`

**ขั้น 3 — คลิป** (ต่อคลิป): อ่านผลสคริปต์ → ตัดสิน P2 / P3 ตามนิยาม · ดูภาพรวมด้วย `clip-sheet.mjs` หรือเฟรมจาก `check-clip.mjs` อย่างน้อย 3 เฟรม (ต้น · กลาง · ท้าย) เพื่อยืนยันว่า "จอว่าง" ที่สคริปต์เห็นคือจอขาวจริง (ไม่ใช่หน้าตารางว่างที่ตั้งใจถ่าย) · **1 คลิปต่อ 1 TC** (R61) เว้นแต่ brief ยกเว้น · > 10 MB เตือน · < 3 วินาที = เทสไม่ได้เปิดหน้า
```bash
node .claude/skills/cortex-card-test/scripts/clip-sheet.mjs "<คลิป.webm>" ".cache/evidence-check/<ชื่อ>-sheet.png"
```

**ห้าม**: แก้ / ลบ / เปลี่ยนชื่อไฟล์หลักฐาน · รันเทสใหม่ · เรียก Linear · เขียนไฟล์นอก `.cache/evidence-check/` · ตัดสิน "ผ่าน" โดยไม่ได้เปิดภาพ

## ผลลัพธ์ที่ต้องคืน (ภาษาไทย)

1. **สรุป 2 บรรทัด**: ตรวจกี่ภาพ กี่คลิป · TC ที่แนบได้เลย / ต้องรันใหม่ · ปัญหา P1–P4 พบอย่างละกี่จุด
2. **ตารางต่อ TC**: TC · Expected (ย่อ) · ภาพที่พิสูจน์ (เลขไฟล์ + **ข้อความที่ยกจากภาพ**) · กรอบล้อมอะไร · ผล (ผ่าน / ไม่ผ่าน P? / ก้ำกึ่ง) · คลิป (ผ่าน / P2 / P3 + ความยาว · ขนาด · ช่วงที่มีปัญหาเป็นวินาที)
3. **รายการที่ต้องรันใหม่** พร้อมสิ่งที่ spec ต้องแก้ เป็นข้อเสนอ เช่น "step 7: `expected(row)` ล้อมแถว `med0000007` แทนทั้งตาราง" · "หลัง `showCompareTable` ใส่ `holdForClip(page, 2000)`" · "เรียก `restartVideo(page)` หลัง iframe เวชระเบียนพร้อม (จอว่างตอนต้น 6 วินาที)" · "ภาพ A-06 ไม่มีกรอบ: เพิ่ม `markEvidence(expected(…))` ก่อนจบ step" — เสนอเท่านั้น ไม่แก้เอง
4. **ภาพก้ำกึ่ง** ที่ session หลักต้องเปิดดูเองก่อนแนบ (ระบุเลขไฟล์ + เหตุผล)
5. **สิ่งที่ตรวจไม่ได้** และเหตุผล
6. **กับดักใหม่** (ถ้ามี) 1 บรรทัด/ข้อ
