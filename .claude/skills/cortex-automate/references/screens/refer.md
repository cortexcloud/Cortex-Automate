- เมนูซ้าย `ทะเบียนผู้ป่วย` = iframe เวชระเบียน (`/reception/embedded/patients/<HN>/info` · `receptionFrame()`) ปุ่ม `แก้ไขข้อมูลผู้ป่วย` → ฟอร์มเดียวกับเวชระเบียน (`email` · `middleName` · `submit-button`) · **ฟอร์มโหลดค่าตามหลังแล้วล้างช่องที่เพิ่งกรอก** → กรอกจนค่านิ่ง 2 วินาทีก่อนบันทึก
  - **กดแก้ไข URL เหลือ `?actions=patientEdit` → บันทึกแล้ว `?views=patientInfo` (en / vn หาย แถบ Visit หาย)** → เมนู `เอกสาร` ปุ่ม `สร้างเอกสาร` disabled + tooltip "กรุณาเปิด Visit ก่อนสร้างเอกสาร" = บั๊ก SBH-1384 ยังอยู่บน dev-x (ต้องออกแล้วเข้า EMR ใหม่)
- เมนูซ้าย `ประวัติการรับบริการ` → คลิกเซลล์ EN → แผง `แก้ไข Visit` (URL ต่อท้าย `&actions=editVisit&views=serviceHistory&editVN=`) · แก้ checkbox `ต้องการรับยาทางไปรษณีย์` (ติ๊กซ้ำจนนิ่ง — ฟอร์มล้างค่าเหมือนกัน) → `บันทึก` → แจ้งเตือน "Visit saved successfully" · en / vn ยังอยู่ → สร้างเอกสารได้
- เมนู `เอกสาร`: ปุ่ม `ตรวจสอบเอกสาร ORS` / `สร้างเอกสาร` / `อัปโหลด` · ตาราง `tr.ant-table-row` (ใหม่สุดบน) ประเภท "ส่งต่อไปสถานพยาบาลอื่น" · ชื่อ "Referral for Continued Examination or Treatment" · ปุ่มในคอลัมน์จัดการ: View (ไอคอนตา) / ดาวน์โหลด / แก้ไข · ว่าง = `.ant-table-placeholder` (ข้อความ "ไม่มีข้อมูล" ในแผงมี 2 ตัว — อย่าใช้)
- `สร้างเอกสาร` → แผงขวา `สร้างเอกสาร` → `.ant-select` ที่มี "ค้นหาเอกสารที่ต้องการสร้าง" (ไม่ใช่ช่อง ประเภท) พิมพ์ "ส่งผู้ป่วย" → `แบบสำหรับส่งผู้ป่วยไปรับการตรวจหรือรักษาต่อ` · ช่องบังคับ วันที่ (เติมแล้ว) · `สถานพยาบาลปลายทาง` (AutoComplete พิมพ์ชื่อ รพ.) · radio ประเภทการส่งต่อ (รับไว้รักษาต่อ / ตรวจชันสูตร / คุมไว้สังเกต / ขอทราบผล) · `การวินิจฉัยโรคขั้นต้น` (พิมพ์ K30 → Functional dyspepsia) · textarea `สาเหตุการส่งต่อ` · checkbox `พิมพ์อัตโนมัติเมื่อบันทึก` (ติ๊กมาให้ — เอาออกในเทส)
  - `บันทึก` = `POST /cortex-api/reports/generate` (report `id 121` · `documentIndexParams {hn, vn, en, visitClassCode: OPD, documentTypeId: 136}`) → 200 `application/pdf` + header `x-document-index-id` / `x-document-id` → แจ้งเตือน "สร้างแบบสำหรับส่งผู้ป่วยไปรับการตรวจหรือรักษาต่อสำเร็จ" (ไม่สำเร็จ = "…ไม่สำเร็จ") · รายการเอกสารไม่รีเฟรชเอง → กดเมนูเอกสารซ้ำ
  - View → `GET /cortex-api/documents/<id>/file` → dialog class `_pdf-viewer-modal_` (กล่อง `.ant-modal-container` · ตัวแสดง PDF ของ Chrome) — อ่านข้อความด้วย pdf.js ฝั่ง node (`pdfjs-dist/legacy/build/pdf.mjs`) ภาษาไทยตรง · PDF หัว "โรงพยาบาลมหาวิทยาลัยนเรศวร" (template ของ dev-x)
- แผงเอกสารแคบเมื่อเปิดแผง คำสั่งการรักษา / สร้างเอกสาร คู่กัน → ปุ่ม View ซ่อนหลังแผงข้างๆ กรอบหลักฐานลอย → ปิดแท็บ dockview (`[data-testid="patient-dockview-tab"]` → `.dv-default-tab-action`) ก่อนถ่าย · เมนูซ้ายกางค้างหลังกดเมนู → คลิกที่ว่างของเนื้อหาให้หุบ

### OPD → Discharge (พยาบาล) แบบ Refer out (SBH Prod 19 ต.ค. 2026 · Mock UAT REFER-01)
- ล็อกอิน Prod: หน้า `/cortex/apps` พาไป Keycloak ทันที ไม่ผ่านหน้า welcome แล้ว → `auth.setup.ts` รอปุ่ม "ลงชื่อเข้าใช้" **หรือ** `#username` · Prod ช้ามากช่วงบ่าย (เปิดหน้าแอปใหม่ ~2 นาที · เวชระเบียน iframe ว่างครั้งแรก)
- สิทธิในแผงเปิด Visit: ตารางสิทธิใส่ `H02 - เงินสด เบิกได้` มาให้ (ลบไม่ได้) → ช่อง combobox ใต้ข้อความ `สิทธิการรักษา` พิมพ์ "UC" → `.ant-select-item-option[title="H03 - สิทธิ UC"]` ได้แถวที่ 2 → ลากปุ่ม `holder` ขึ้นเป็นลำดับ 1 (mouse down/move/up) · แถบหัว Visit ขึ้น "สิทธิ UC +1"
- สถานะ Visit OPD ในช่องสถานะบนแถบหัว: เช็คอิน → `พร้อมตรวจ` → `ตรวจเสร็จ` (ผู้ใช้สั่ง — ไม่มีตัวเลือก "กำลังตรวจ") = graphql `TransitionEncounterStatus` ไม่มีหน้าต่างยืนยัน
- **จำหน่ายต้องใช้บัญชีพยาบาล**: ปุ่ม `จำหน่าย` ในคอลัมน์จัดการของรายการผู้ป่วยนอก — บัญชีแพทย์ (user1) disabled tooltip "ผู้ใช้งานบทบาทแพทย์ไม่สามารถจำหน่ายผู้ป่วยได้" · Nurse (x-nurse1 · "Nurse SBH") กดได้ → **จำหน่ายทันที** (`DischargeEncounterStatus` accepted · สถานะเป็น จำหน่าย) แล้วพาไปหน้าผู้ป่วย `?actions=dischargeForm&fromApp=opd&preset=opdDischargedV2`

- **ช่องสถานพยาบาลปลายทางค้นไม่ได้**: `GET /generated-emr-api/hospitals?filterActiveEquals=true&filterOrCodeContains=…&filterOrNameContains=…` → 422 `unrecognized_keys` ทุกครั้ง → ไม่มีตัวเลือก · **พิมพ์ชื่อเองแล้วค่าค้าง บันทึกได้** (ผู้ใช้อนุญาต R63) · การวินิจฉัยโรคขั้นต้นค้นด้วย `GET /diagnosis-search/icd10/?q=K30` → ตัวเลือกเป็นชื่อโรค ("Functional dyspepsia") · บันทึกเอกสาร = `POST /cortex-api/reports/generate` (คืน PDF) + แจ้งเตือน "สร้างแบบสำหรับส่งผู้ป่วยไปรับการตรวจหรือรักษาต่อสำเร็จ" · "เอกสารที่สร้างแล้ว 1"
