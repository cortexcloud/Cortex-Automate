- ค่าตั้งต้นของคำแนะนำ / สถานที่ = master data ของ **หน่วยบริการ (queue service unit)** ไม่ใช่ hard code: graphql `queueServiceUnits(ids:[…]){ locationDescription locationDescriptionInfo{th en} appointmentInstruction{th en} routingClinics{id} }` (อ่านอย่างเดียว · หน้าตั้งค่าหน่วยบริการแก้ได้) · dev-x: ทุกหน่วยบริการที่มีสถานที่ใช้ข้อความตัวอย่างเดียวกัน · MED (11) → หน่วยบริการ 4 · AFI (10) / ARI / DIAR → 325 · ค่าตั้งต้นคำแนะนำโหลดเมื่อคลินิกมี `queueServiceUnitId` — 23 ต.ค. ช่องว่างทุกคลินิกที่ลอง
- Shortcut `/` (label `appointment-instructions` · graphql `effectiveShortcuts(input:{clinicId,labelNames})` · dev-x มี 1 รายการ "ทดสอบสร้างคำแนะนำให้บริการ") · **tiptap `allowedPrefixes [" "]` → `/` ต้องอยู่ต้นบรรทัด / หลังเว้นวรรค** พิมพ์ติดข้อความไทยแล้วรายการไม่ขึ้น · รายการ = `[data-tippy-root] [role=listbox]` option · Escape ปิดรายการ ("/" ค้างในข้อความ)
