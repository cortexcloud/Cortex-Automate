## UAT-ER-01 · ER/EMR — เพิ่ม 1 ขั้นตอน (4.9.8.9.2)

| ขั้นตอน | Test Step |
|---|---|
| เลือกอาการนำจากรายการแนะนำ | 1. เปิดหน้าผู้ป่วย >> ER Physician Note (จากแท็บด้านขวา) >> ส่วน Chief Complaint - General / 2. กดปุ่มอาการนำที่ระบบแนะนำ (Common chief complaints) อย่างน้อย 1 รายการ / 3. ผลที่ควรเห็น: ระบบแสดงรายการอาการนำที่พบบ่อยให้กดเลือก และอาการที่กดถูกเลือกในบันทึก **[ต้องยืนยัน: อาการที่กดไปแสดงที่ช่องไหน]** |

> ข้อสังเกต: ชุดอาการที่แนะนำตอนนี้เป็นชุดทั่วไป (ปวดไหล่ คอ · ปวดหลัง · นวดเพื่อสุขภาพ …) ไม่ใช่ชุดอาการ ER — ถ้าทีมต้องการชุด ER ควรแจ้ง Dev ก่อนเทส UAT

## UAT-ER-03 · ER/REG ระบุ HN ภายหลัง — เพิ่ม 3 ขั้นตอน (4.9.8.1.5)

| ขั้นตอน | Test Step |
|---|---|
| ลองเชื่อมโยงผู้ป่วยขณะ Visit ยังเปิด | 1. เมนู เวชระเบียน >> ค้นหา HN ชั่วคราว (Dummy) ของผู้ป่วยรายนี้ >> ข้อมูลผู้ป่วย >> ปุ่ม ⋮ >> "เชื่อมโยงผู้ป่วย" / 2. เลือก HN จริงของผู้ป่วยเป็น HN หลัก และ HN ชั่วคราวเป็น HN รอง / 3. ผลที่ควรเห็น: ระบบไม่ให้เชื่อมโยง และแจ้งว่ายังมี Visit ที่ยังไม่ปิด **[ต้องยืนยัน: ข้อความจริงบนจอ]** |
| ปิด Visit ของผู้ป่วยไม่ระบุตัวตน | 1. หลัง Disposition (แถว 55) ดำเนินการชำระเงินและปิด Visit ที่การเงินให้เรียบร้อย / 2. ผลที่ควรเห็น: Visit ER ของ HN ชั่วคราวปิดแล้ว ไม่มีบัญชีค้าง |
| เชื่อมโยง HN ชั่วคราวเข้ากับ HN จริง | 1. เมนู เวชระเบียน >> ข้อมูลผู้ป่วย (HN ชั่วคราว) >> ปุ่ม ⋮ >> "เชื่อมโยงผู้ป่วย" / 2. เลือก HN จริงเป็น HN หลัก · HN ชั่วคราวเป็น HN รอง · ระบุเหตุผล >> ยืนยัน / 3. ผลที่ควรเห็น: เชื่อมโยงสำเร็จ HN ชั่วคราวถูกล็อกไม่ให้เปิด Visit ใหม่ และค้นด้วย HN จริงแล้วเห็นประวัติการมา ER ครั้งนี้ **[ต้องยืนยัน: ประวัติย้ายมาอยู่ HN จริงหรือไม่]** |

> เงื่อนไข: ต้องมีผู้ป่วยที่มี HN จริงอยู่ในระบบ และเลขบัตรประชาชนตรงกัน (ระบบมีเงื่อนไขห้ามเชื่อมโยงเมื่อเลขบัตรไม่ตรง)
> ไม่ได้ร่าง: การเปลี่ยนจาก "ระบุ HN" เป็น "ไม่ระบุ HN" ใน Visit (ครึ่งแรกของข้อ 4.9.8.1.5) เพราะระบบยังไม่มีทางทำ — ยังเป็น gap

## UAT-ER-08 · ER/EMR เลือกโซน — เพิ่ม 3 ขั้นตอน (4.9.8.8.4)

| ขั้นตอน | Test Step |
|---|---|
| กรองดูเฉพาะโซน | 1. ห้องฉุกเฉิน >> แดชบอร์ด / คิว >> มุมมอง "รายการ" >> ตัวกรอง "โซน" เลือก 1 โซน (เช่น โซนเหลือง) / 2. ผลที่ควรเห็น: ตารางแสดงเฉพาะผู้ป่วยในโซนที่เลือก · ขึ้นป้าย "โซน: <ชื่อโซน>" ใต้แถบตัวกรอง · ตัวนับ ESI นับตามโซนที่เลือก |
| เพิ่มโซนบริการ | 1. ตั้งค่าผู้ดูแลระบบ >> สถานที่ (Location) >> เพิ่ม Location ประเภท Emergency Room (เช่น "ER โซนทดสอบ") แล้วบันทึก / 2. ผลที่ควรเห็น: โซนใหม่ขึ้นในตัวกรอง "โซน" ของ ER และเลือกได้ตอนคัดกรอง **[ต้องยืนยัน: ยังไม่เคยลองบน dev-x]** |
| ลดโซนบริการ | 1. ปิดใช้งาน Location ที่เพิ่มในขั้นก่อน / 2. ผลที่ควรเห็น: โซนนั้นไม่ขึ้นในตัวกรอง "โซน" และตัวเลือกโซนตอนคัดกรองอีก **[ต้องยืนยัน]** |

> ข้อควรระวัง: ขั้นเพิ่ม / ลดโซนแก้ข้อมูลตั้งค่าที่ทุกคนใช้ร่วมกัน ต้องใช้ User ผู้ดูแลระบบ และควรเทสบน Environment ทดสอบ แล้วปิดโซนทดสอบทุกครั้งหลังจบ

## UAT-ER-11 · ER/QUEUE — เพิ่ม 3 ขั้นตอน (4.9.8.3.5 · 4.9.8.3.3)

ต้องมีผู้ป่วยอย่างน้อย 3 รายที่คัดกรองแล้วและมีเลขคิว (ต่อจากขั้น "พิมพ์บัตรคิว")

| ขั้นตอน | Test Step |
|---|---|
| เปิดจอ ER TV | 1. เปิดหน้าจอ ER TV (`/cortex/public/er/tv-queue` ไม่ต้องล็อกอิน) บนจอทีวีหรือแท็บใหม่ / 2. ผลที่ควรเห็น: ตารางผู้ป่วยแสดง ลำดับ · หมายเลขคิว · ชื่อ - สกุล · สถานะการรักษา พร้อมป้าย ESI ตามสีระดับความรุนแรง · ชื่อผู้ป่วยถูกปิดบางส่วน |
| เรียกคิวตามลำดับ | 1. ห้องฉุกเฉิน >> แดชบอร์ด / คิว >> มุมมอง "รายการ" แท็บ "ผู้ป่วยปัจจุบันใน ER" >> คอลัมน์ "คิว" กดปุ่มเรียกคิว (ไอคอนลำโพง + เลขคิว) ของผู้ป่วยแถวบนสุด / 2. ผลที่ควรเห็น: ขึ้นข้อความ "ส่งคิว <เลขคิว> ไปยังจอ ER แล้ว" · จอ ER TV แสดงเลขคิวนี้ในการ์ด "กำลังเรียก" ภายในไม่กี่วินาที |
| เรียกคิวข้ามลำดับ | 1. กดปุ่มเรียกคิวของผู้ป่วยที่ไม่ใช่ลำดับถัดไป (เช่น แถวล่างสุด) / 2. ผลที่ควรเห็น: เรียกได้โดยไม่ต้องเรียกตามลำดับ · จอ ER TV แสดงคิวที่เพิ่งเรียกในการ์ด "กำลังเรียก" และคิวก่อนหน้าย้ายไปส่วน "เรียกแล้ว" |
