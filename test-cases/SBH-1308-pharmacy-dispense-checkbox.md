### วิธีเตรียมข้อมูลทดสอบ (ใช้กับทุก TC)

1. ลงทะเบียนผู้ป่วยใหม่ที่ ER (`/cortex/er/triage` → "ผู้ป่วยใหม่") แล้วกด "ยกเลิก" ที่ modal "เปิด Visit ER" → ได้ HN ไม่มี visit
2. เวชระเบียน → ค้นหา HN → "Visit ใหม่" → "Walk-in ไป คลินิก" = "SBH - ห้องตรวจสระบุรี" (Location ขึ้น "แผนกอายุรกรรม") → "สร้าง"
3. แอปผู้ป่วยนอก → เลือกสถานที่ "แผนกอายุรกรรม" → แท็บ "คำขอ Walk-in" → "ลงตาราง" → แพทย์ "นาย ทดสอบ มานะ" + ช่วงเวลา → "บันทึก" → แท็บ "ทั้งหมด" → "เช็คอิน"
4. คลิกชื่อผู้ป่วย → หน้า OPD ส่วน "คำสั่งการรักษา" → ช่องค้นหา Order พิมพ์รหัสยา (ใช้ได้เฉพาะ med0000005–med0000008 ตามกฎ R25) → กรอกขนาดยา / Route / ความถี่ / จำนวนที่จ่าย (หรือเลือกวิธีใช้สำเร็จรูป เช่น "1 tab po od pc") → "เพิ่มลงตะกร้า" ทีละรายการจนครบ 3 รายการ → "ส่งคำสั่ง"
5. แอปห้องยา → เลือกห้องยา **"ห้องยาชั้น 1"** + ช่องบริการ → แท็บ "Order รอยืนยัน" → คลิกแถวผู้ป่วย → หน้า "รับออเดอร์" → "สร้างใบยา"
6. แท็บ "ใบยารอจัด" → เปิดใบยา → "จัดยาแล้ว" → แท็บ "ใบยาจัดแล้ว" → เปิดใบยา → "ยืนยันรอจ่าย"
7. แท็บ **"ใบรอจ่าย"** → คลิกแถวผู้ป่วย → หน้าใบยา สถานะ "ใบรอจ่าย" (หน้าที่ใช้เทสทุก TC)
- TC ที่ต้องกด "จ่ายยา" จริง (TC-005, 006, 008) ใช้ใบยาใหม่ทุกครั้ง เพราะจ่ายแล้วใบยาย้ายไปแท็บ "จ่ายยาแล้ว"
- ปิด "Print บัตรคิวอัตโนมัติ" (ตอนลงตาราง) และ "Print ฉลากยาอัตโนมัติ" (ตอนสร้างใบยา) ถ้าเครื่องที่เทสไม่มีเครื่องพิมพ์

  - ติ๊กไว้แล้วออกจากหน้า/reload สถานะติ๊กคงอยู่หรือไม่ ไม่ได้ระบุ → QA ตัดออกจาก scope แล้ว
  - เมนู "…" (ยืนยันจ่ายยา / ยกเลิกจ่ายยา) ยังอยู่หรือเอาออก ไม่ได้ระบุ → QA ตัดออกจาก scope แล้ว
- **Validation**
  - AC บอกแค่ "ไม่อนุญาตให้จ่าย" ไม่ได้บอกรูปแบบ → ใช้ disabled ตาม comment dev (14 ก.ย. 2569) ไม่มีข้อความแจ้งเตือน
- **Error handling**
  - ไม่ระบุกรณีจ่ายยาไม่สำเร็จ (เช่น ระบบ error ตอนกด "จ่ายยา")
- **Permission / role**
  - ไม่ระบุ role ที่ใช้หน้านี้ → ใช้ user1 (ใช้ได้ครบทุกขั้นตอนตอนสำรวจ)
- **Edge cases**
  - ใบยาที่มีรายการเดียว, รายการยาที่ถูกยกเลิก/จ่ายบางส่วนไปแล้ว ไม่ได้ระบุ → ไม่มี TC
